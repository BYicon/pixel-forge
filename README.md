# Pixel Forge

Pixel Forge 是一个页面设计素材库，用来制作、收集和整理好看的网页，供日常开发和 AI 生成页面时参考。

这里不只是保存 HTML 模板，也关注页面的视觉风格、布局、排版和交互细节，让 AI 在生成页面时有更具体的设计依据。

## 现有模板

### AIGC 移动端聊天界面

[查看模板文件](templates/aigc-chat-mobile.html)

一个移动端优先的 AI 创作助手界面，使用浅色背景、灰绿色调和简洁的对话布局，也适配桌面屏幕。适合参考聊天产品的空状态、输入区、素材选择、对话历史和作品展示方式。

- 支持切换对话和创作模式、添加素材、预览示例作品，以及体验版本修改、停止和重试等交互。
- 对话和草稿保存在当前浏览器；原始附件只在当前页面会话中保留，刷新后需要重新选择。一次最多添加 4 个素材，每个不超过 50 MB。
- 这是前端交互演示，未接入 AI 服务。图片、视频和动图模式使用示例 SVG，不会生成真实视频或 GIF；语音输入依赖浏览器支持。

**预览方式：** 下载或克隆仓库后，用浏览器打开 `templates/aigc-chat-mobile.html`。模板采用单文件 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 可以收集什么

- 完整页面：落地页、后台页面、个人主页等。
- 页面片段：导航、卡片、表单、列表和空状态等。
- 设计参考：配色、字体、间距、动效和不同风格的示例。
- 给 AI 的说明：设计要求、适用场景和使用方式。

## 如何使用

1. 将页面或素材放入本项目，并为其取一个容易辨认的名字。
2. 记录适用场景、运行或预览方式，以及需要注意的依赖。
3. 让 AI 读取相关素材，并结合具体项目的内容、技术栈和设计需求进行实现。

例如：

> 请参考 `pixel-forge` 中适合后台管理的页面，分析它的布局、配色和组件样式，再结合当前项目的技术栈实现我的页面。

使用时应根据实际内容调整设计，保持页面的一致性、可读性和可用性，而不是简单复制示例。
